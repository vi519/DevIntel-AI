# Compareo

AI-powered engineering candidate intelligence for recruiters and hiring teams.

## Overview

Compareo compares GitHub and LeetCode profiles to extract actionable engineering signals and generate professional comparison reports.

## Features

- Candidate input for GitHub & LeetCode usernames
- GitHub and LeetCode analysis with evidence-based insights
- Side-by-side comparison dashboard
- AI-generated summaries and interview recommendations
- Responsive recruiter-friendly UI
- PDF report export flow
- API key management for OpenAI/Gemini

## Tech stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Recharts
- jsPDF + html2canvas

## Setup

1. Install dependencies

```bash
npm install
```

2. Run development server

```bash
npm run dev
```

3. Open http://localhost:3000

## Environment

Copy `.env.example` to `.env.local` if you need future server-endpoints or keys.

## Deployment

Deploy to Vercel from the repository root. The app is ready for static and serverless deployment.
